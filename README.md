# Haberman Survival Data - Exploratory Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Haberman Survival Dataset. The dataset contains information about patients who underwent breast cancer surgery.

The purpose of this project is to explore the dataset, understand the distribution of variables, calculate statistical measures, and visualize the data.

## Dataset
- Total records: 306
- Total features: 4
- Age of patient
- Year of operation
- Number of positive axillary nodes
- Survival status

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib

## Analysis Performed
- Displayed the first and last rows of the dataset.
- Checked dataset shape, information and statistical summary.
- Calculated mean, median, minimum and maximum age.
- Calculated average positive axillary nodes.
- Compared average age and node counts across survival-status groups.
- Analyzed operation-year record counts.
- Checked missing values and duplicate rows.
- Created two visualizations.
